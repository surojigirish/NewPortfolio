GIRISH SUROJI PORTFOLIO — UPDATED MOSCOW DARK TEMPLATE

START HERE
- index.html is the homepage for GitHub Pages.
- Keep the css/, js/, fonts/, and images/ folders in the same directory as index.html.

EDIT YOUR PORTFOLIO IMAGES
- Replace images/projects/project-1.jpg through project-9.jpg with your own project screenshots.
- Keep the same filenames to avoid changing the HTML paths.
- Edit the project card names in index.html in the section marked "Portfolio Starts".
- Edit each project detail panel near the end of index.html ("Portfolio Panel Items Starts").
- The included images are template placeholders until you replace them.

PROFILE IMAGE
- Replace images/profile.jpg with your own portrait if you want one shown in the About section. If you do not have one yet, you can leave the placeholder or remove that image block later.

CONTACT
- The contact form opens the visitor's email app with a prefilled message to girishsuroji@gmail.com. GitHub Pages does not run PHP, so this avoids a non-working PHP form.

PUBLISH
Upload the contents of this ZIP (index.html and all folders) to the root of your GitHub Pages repository, replacing the old site files. Keep all asset folders together.
